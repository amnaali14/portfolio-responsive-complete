# Portfolio - Amna Ali

A minimal, responsive portfolio to showcase skills in web development and AI-driven cybersecurity.

## Quick start
- Open `index.html` in a browser to preview locally.
- Edit content in `index.html` (About, Skills, Projects, Contact).
- Styles in `assets/css/styles.css`, scripts in `assets/js/main.js`.

## Contact form
- The form posts to Formspree. Replace the placeholder action in `index.html`:
  - Find: `https://formspree.io/f/your-unique-id`
  - Replace with your Formspree endpoint from your dashboard.
- JS provides basic validation; it will block submission on invalid input.

## Deploy
### GitHub Pages
1. Push this repo to GitHub.
2. In Settings → Pages, set Source to `Deploy from a branch`, select your default branch and `/root`.
3. Wait for the site URL to appear (usually `https://<username>.github.io/<repo>`).

### Netlify (recommended)
1. Drag-and-drop the project folder to Netlify or connect the Git repo.
2. Build command: none. Publish directory: the repository root.
3. Optionally set a custom domain in Netlify DNS.

## SEO
- Update `<title>` and meta description in `<head>` of `index.html`.
- Social sharing image is `preview.png`. Replace with your own for better previews.

## Assets
- Placeholder SVGs live in `assets/img/`. Replace with your own images and update paths if needed.
